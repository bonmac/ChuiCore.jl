# Phase 5 plan: the Documenter site (BRIEF.md, Phases §5)

Lane `phase5-docs`, branch `feat/phase5-docs` from main 4a0ea88. No behaviour change in `src/`:
docstring edits only. v0.1.0 is NOT tagged here.

## Goal

A Documenter site laid out as ecosystem ADR-0008 fixes it (tutorials / howto / explanation /
reference / changelog), with every exported and public name documented with a doctested example
and a runtime cost, doctests run in the `:doctest` tag on stable Julia, and a README.

## Gates added

- `test/doctest_tests.jl`: a `:doctest` item running `Documenter.doctest(ChuiCore; manual = true)`
  (docstrings and `docs/src`), stable only (runtests.jl already excludes `:doctest` when
  `CI_STABLE=false`). Documenter joins `test/Project.toml`.
- `test/quality_tests.jl`: every exported/public name's docstring has a `jldoctest` (or is listed
  in `docs/doctest-exemptions.md`) and states a cost (`cost` appears in the text). Names whose
  binding belongs to another module (`⨟`, `opcompose`: CompositionsBase) are skipped and covered by
  the composition tutorial.

At the scaffold commit 182 owned names lacked a jldoctest or a cost statement (algebra 27,
laws.jl 19, classes 66, transducers 24, schemes 30, optics/lazy/banner 16). The reference was
split into eight pages: the one-page core reference was already 121 KiB, and Documenter fails
above 200 KiB.

The lane owner (this lane) writes the scaffold, make.jl, index, howto, explanation pages,
reference pages, the gates, README, HANDOFF and the changelog fragment, then merges the four
sub-lane branches (disjoint files, so no conflicts expected) and runs every gate.

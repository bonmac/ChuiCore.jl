## Rejected during the lane (measured)

- Forcing `pipe` to specialize on its function vararg: a first measurement showed 48–96 B, but it
  came from the measuring harness (`@allocated f(args...)` with functions in `args`); real calls
  allocate 0 B before and after, so the change was reverted.
- A faster `partial(::Max, …)` via `maximum` on 1.10: Base's `maximum` is 4.1 μs against 5.5 μs
  for 10^4 `Float64`, inside the noise and the budget; not worth a second code path.
